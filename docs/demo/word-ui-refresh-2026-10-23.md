# Word 批注与问题检索界面更新

本次更新针对原生批注消失、问题定位卡顿、缺少检索开关和卡片文字拥挤。

## 实现

- 每个合并问题在首个位置添加一条 Word 原生批注，其他命中仍高亮并可逐处定位；重复分析先清除工具自己拥有的批注和书签，保留人工批注。位置和原高亮元数据隐藏在批注内。
- 批注正文仅显示来源、规则、期望值和实际值。按换行读取字段，保留合并实际值中的分号，兼容旧版行内批注。
- 定位直接使用当前窗口的缓存 Word.Range，移除每次点击时的整篇 DOCX 快照写入；鼠标在检索窗格内时跳过悬停的 Word COM 查询。
- 功能区提供“打开检索/关闭检索”切换，与窗格 X 的关闭状态同步。分析和修复继续在当前文档中进行。
- 检索卡片增加标题间距、固定标签列、内容换行和自适应高度。南开紫、暖白与金色强调统一到卡片和功能区；校园页眉及九枚功能图标由 GPT-image 生成，不使用学校官方印章。

## 验证边界

测试项目 Release 构建通过，0 警告、0 错误。标准 VSTest 的批注写入与匹配回归 15/15 通过；沙盒内的 testhost IPC 无法连接，在沙盒外执行同一组用例后正常通过。签名 VSTO Release 构建成功。独立检查已确认 Ribbon XML、检索开关回调及九个图标的 IPictureDisp 返回值有效。

当前 Windows 桌面显示锁屏，按电脑控制规则已停止 UI 输入；因此本次尚未确认真实 Word 中的批注显示、开关、多次定位耗时及最终视觉效果。原生批注的边框颜色、答复与解决按钮由 Word 自身控制。最新签名包使用独立输出目录，避免覆盖 Word 正在加载的旧 DLL；须关闭 Word 后安装再验收。

实机复验只使用 `tests/fixtures/synthetic/full-thesis/synthetic_complete_thesis.docx` 的独立测试副本。参考 `word-acceptance.md` 完成后再将 PR 从草稿转为可审核状态。
