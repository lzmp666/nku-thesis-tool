## 4. 访谈提纲（固定四问 + 一个二选一，不开放式提问）

1. 学校/期刊的规范原文或链接，最常出错的 3–5 个格式项。
2. 现在怎么改，最烦的是哪一步。
3. 用不用 Zotero / EndNote，公式用什么写（Word 自带 / MathType / LaTeX）。
4. 愿不愿意给脱敏后的样本（不留原件）。

二选一必须原样给两条路：

- **A 写完批量修（现状）**：写完跑一次命令，一次改到位。
- **B 写作期实时引导**：边写边提示。代价是 Word 里要常驻加载项，误报会烦，每敲一句都要判定，而写的时候本来就最烦被打断。

默认判断是 A。要推翻它必须拿到「有人在写到一半就卡死、最后放弃」的具体例子，否则不立项。问的时候不许把 B 描述成更好的方向，也不许替受访者选。
