## 2. 未纳入项（按规范本身未规定，不猜测）

- 表格内文字、脚注字号：S2026 未规定 → 不设值（沿用 T3）。
- 书脊（4.3）：固定版式说明，仿宋 14 磅/固定 16 磅/距边界 5cm，供印刷参考 → 记录但不纳入自动检查。
- 真人材料（Word 实机截图、真实脱敏论文、工/理科访谈）：不作为规则条文依据，仅作验收证据；本次以本机确定性校验与合成样本回归替代，不冒充真人材料。

## 3. RFC-1~7 落地决策（一次性定案）

| RFC | 原未决点 | 决策 | 依据 |
|---|---|---|---|
| RFC-1 | 字体脚本槽位映射 | 中文字体 → `w:rFonts/@eastAsia`；西文 → `@ascii` + `@hAnsi`；判定用 PartFormatReader 的 IsSimSun/IsSimHei/IsArial/IsTimesNewRoman 等价函数 | Word OOXML 标准 + 现有 PartFormatReader 实现 |
| RFC-2 | 部件边界识别 | 按 `w:outlineLvl`/HeadingN 样式链识别标题层级；摘要/目录/参考文献/附录/致谢/符号表按标题文字 + 样式识别，不用字体特征猜 | S2026 4.5–4.8 分节标题 + 现有分析器实现 |
| RFC-3 | 字体名等价 | 宋体=SimSun、黑体=SimHei、仿宋=FangSong、Arial、Times New Roman 五组，大小写不敏感；未收录字体名判「未判定」不硬判 | Word 中文字体常见别名 + PartFormatReader |
| RFC-4 | 行距豁免 | 段落含数学表达式（OMML `m:oMath`）时，固定值 20 磅豁免，标「未判定」而非「不合规」 | S2026 4.7 原文括注「段落中有数学表达式时，可根据表达需要设置该段的行距」 |
| RFC-5 | 数值口径 | 字号按 `w:sz` 半点整数直接判等；长度按 twips 换算 cm，容差 0.05cm；行距 twips 精确判等 | OOXML 单位定义 |
| RFC-6 | 封面豁免 | 封面/题名页只检查内容是否提供，不检查字体字号格式 | S2026 4.2 原文「封面已有固定版式，只须提供有关内容」 |
| RFC-7 | 目录检测对象 | 检查目录段落的样式与缩进属性，不依赖 TOC 域展开结果（域结果由 Word 生成，静态 XML 不可靠） | 静态 XML 可判定性 + 现有 TocFormatAnalyzer 实现 |

## 4. 与既有开放口径的关系

- 各分析器 `NotChecked` 中仍保留的「未判定」项（如标题序号空一汉字宽度、二级三级加粗原文未写）**不因本次转正而变为已判定**：
  这些不是规则未核定，而是 S2026 原文确实未给出可机器判定的数值/布尔口径，按「判不出不冒充合规」继续列未判定。
- 页码定位采用确定性估算（页面尺寸/边距/行距/分页符），不依赖 Word COM；估算值与 Word 实机分页可能有差异，报告中标注为「估算页码」。新增 `page-map <docx>` 命令输出每段估算页码（`--json` / `--issues`），3 项回归测试验证单调性、强制分页与诚实标注。

## 5. 实现边界决策（不是缺陷，按铁律保留）

| 边界 | 表面现象 | 复核结论 |
|---|---|---|
| VSTO 混合值修复 | `WordParagraphValueMapper.Alignment/LineSpacing`、`WordRepairSession` 对混合值/未知 RuleId 抛异常 | 这是「选区格式不一致或规则未知时安全停止、不猜测」的防御设计，符合铁律「未知格式、无法安全定位的范围仍停止修复」。`WordParagraphValueMapperTests.RejectsMixedAndUnsupportedValues` 已明确断言拒绝行为，属**已闭环的设计**，不改成猜测式修复。 |

| 真人材料 | Word 实机截图、真实脱敏论文、工/理科访谈缺失 | 不伪造。按授权以公开规范全文 + 本机确定性校验 + 合成样本回归替代，文档与发布说明中如实标注来源类型。 |
